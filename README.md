# Code Demo Typer

**提前准备内容，专注现场讲解。** 在 VS Code 的已有代码中，用任意普通按键逐步输入准备好的代码；保留空格、缩进和换行，删除后还可以重新打回。

适合教程录制、产品讲解、技术分享和现场代码演示。扩展不联网、不采集遥测；演示时不显示通知、状态栏标记或完成弹窗。

## 主要功能

- **10 个独立预设**：分别命名、编辑和保存多行内容。
- **数字快捷键启动**：Ctrl+Alt+1～9、0 一键切换，每次从预设开头开始。
- **在任意位置输入**：在现有代码的光标位置插入，也支持替换选区，不需要新建文件。
- **删除后重打**：退格、Delete 或选区删除后，在删除位置继续按键，优先还原实际删除的文字。
- **空白自动输入**：连续空格、缩进、空行自动成组写入，换行适配当前文件 LF/CRLF。
- **静默演示**：预设耗尽后保持接管，不会把乱按的字符写入；Esc 可立即结束。
- **工作区独立保存**：旧版单预设自动映射到槽位 1。

## 安装与快速开始

1. 从 [GitHub Releases](https://github.com/LaoQiTX/code-demo-typer/releases) 或本地构建结果取得 `.vsix` 文件。
2. 打开扩展面板右上角菜单，选择 **从 VSIX 安装**。更新旧版后按编辑器要求重新加载窗口。
3. 按 **Ctrl+Alt+R** 打开管理窗口，选择槽位，填写名称和完整代码，点击 **保存全部并关闭**。
4. 返回目标代码文件，将光标放在插入位置，按 **Ctrl+Alt+1** 启动第 1 个预设。
5. 随便按字母、数字、符号、空格、回车或 Tab，逐步输入预设。完成后按 **Esc** 恢复正常编辑。

Trae 可使用其“从 VSIX 安装”入口；兼容情况取决于具体版本，尚未在 Trae 实机验证。

## 快捷键

| 快捷键 | 功能 |
| --- | --- |
| Ctrl+Alt+1～9 | 从头启动预设 1～9 |
| Ctrl+Alt+0 | 从头启动预设 10 |
| Ctrl+Alt+R | 打开预设管理窗口，并暂停演示 |
| Ctrl+Alt+D | 暂停/继续当前预设；首次默认使用槽位 1 |
| Ctrl+Alt+Home | 重置当前预设进度及删除记录 |
| Esc | 结束接管 |
| Backspace / Delete | 正常删除，在原位置继续输入可重打 |

macOS 使用 Cmd+Alt。数字快捷键只在代码编辑器获焦时生效；空槽位会静默暂停，不会继续输入上一个预设。切换文件也会暂停。需要继续原进度时使用 Ctrl+Alt+D，数字快捷键会从头开始并清空本次删除重打记录。

在“键盘快捷方式”中搜索 `演示输入` 可调整绑定。扩展命令 ID 为 `codeDemo.preset1` 至 `codeDemo.preset10`，方便自定义键位。

## 预设管理窗口

窗口提供槽位选择、名称、多行编辑器、字符/行数统计、复制到下一槽、清空和统一保存。Tab 在预设编辑框内插入四个空格，粘贴的真实 Tab 会保留。切换槽位保留未保存草稿；只有“保存全部并关闭”才写入工作区存储，直接关闭会放弃本次修改。

## Python 缩进与输入行为

预设按原样插入，不会猜测上下文或自动修复 Python 语法。例如在函数体的空白行插入以下内容时，应在预设中包含四个前导空格：

```python
    temperature = 24
    if temperature > 20:
        print("适合生长")
```

若光标前已经存在四个空格，预设第一行应去掉这四个空格，后续行仍保留需要的缩进。编辑时通过文本编辑 API 写入，避免普通打字触发的自动补缩进。其他扩展、保存时格式化和代码动作仍可能改动文档。

## 删除与恢复

开启演示后删除的真实内容会按位置记录，包括已有代码。将光标放回删除位置，再按普通键便会逐步重打；补完后继续剩余预设。连续退格、连续 Delete、选区删除及跨行删除均有逻辑测试。

记录仅保留在当前会话内；结束演示、切换数字预设、重置进度或重新加载窗口会清除。常规撤销/重做由编辑器处理，不保证能回滚扩展全部内部进度。复杂编辑后可重启预设。

## 边界与常见问题

- **只支持单光标**。多光标状态下不执行演示输入。
- **建议英文输入法**。中文输入法组合过程及其他拦截 `type` 的扩展可能影响效果。
- **不是所有物理按键都会输入**。方向键和 Ctrl/Alt 组合仍保留编辑器功能；普通可输入字符、Enter 和 Tab 才推进内容。
- **空白不是逐个敲入**。一个按键可能连带输出换行和缩进，这是预期行为。
- **直接编辑现有文件**。保存会修改该文件，建议使用版本控制。
- **预设不是密码库**。内容保存在编辑器的本地工作区扩展存储中，不加密、不自动上传。不要放入凭据。
- **未看到输入**：检查当前槽位是否为空或耗尽、是否单光标、是否聚焦目标文件、快捷键是否冲突。

## 开发与开源

MIT 许可，无运行时第三方依赖。需要 Node.js 20+；Windows 上可直接构建：

```sh
npm run check
npm test
npm run package
```

在 VS Code 打开项目根目录，按 F5 启动扩展开发宿主。GitHub Actions 会检查、测试并构建 VSIX artifact。详见仓库中的 CONTRIBUTING.md 与 PUBLISHING.md。

当前发布者 `local-demo` 是本地占位值；公开上架前请改为自己的已注册发布者，并填写真实仓库地址。本项目未自动发布到商店。
